# 高斯光束传播虚拟仿真实验平台

这是一个用于《激光原理》课程设计的纯前端项目，使用 HTML、CSS、JavaScript 实现。

## 当前已实现

- 参数输入：波长 λ、束腰 w0、传播距离 z
- 实时计算：瑞利长度、光束半径、发散角
- 页面响应式布局

## 文件结构

```text
.
├── index.html
├── css/
│   └── style.css
└── js/
    └── main.js
```

## 使用方法

直接用浏览器打开 `index.html` 即可运行。
